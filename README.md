Predictive Analytics for Irish Motor Insurance: Financial Risk Mitigation
Academic Project | MSc in Data Analytics | CCT College Dublin 

Project Overview
This academic project investigates the Irish Motor Insurance landscape, focusing on engineering predictive models to mitigate the financial impact of insurance claims. By synthesizing historical insurance data with external environmental factors, this research aims to optimize the ratio of liquid assets to technical reserves.

Technical Architecture & Pipeline
The project utilizes a robust Python-based ETL pipeline designed to handle heterogeneous data streams:
Meteorological Data Fusion: Automated extraction of global climate data (ERA5) using the CDS API and processing via xarray and cfgrib.
Computational Optimization: Implementation of Multiprocessing and vectorized operations to handle large-scale spatial-temporal datasets.
Statistical Modeling: Application of Z-score normalization, Skewness/Kurtosis analysis, and Scikit-Learn for predictive feature engineering.
Visualization: Interactive data storytelling using Seaborn and Matplotlib to analyze coverage ratios and forecast differences.
